# Data Structures in C

A collection of **Data Structures implementations in C** designed to understand and practice fundamental data structure concepts using structures, pointers, dynamic memory allocation, and modular programming.

---

## Data Structures Covered

* Singly Linear Linked List
* Singly Circular Linked List
* Doubly Linear Linked List
* Doubly Circular Linked List
* Stack
* Queue

---

## Core Operations

Each Linked List implementation includes six major operations:

* `InsertFirst` — Insert a node at the beginning
* `InsertLast` — Insert a node at the end
* `InsertAtPos` — Insert a node at a specific position
* `DeleteFirst` — Delete the first node
* `DeleteLast` — Delete the last node
* `DeleteAtPos` — Delete a node from a specific position

### Additional Operations

* `Display` — Display all elements of the data structure
* `Count` — Count the number of nodes

The **Stack** and **Queue** implementations are also included with their respective fundamental operations.

## Compilation and Execution

The programs can be compiled using **GCC**.

### Compile

Open the terminal in the directory containing the C file and run:

```bash
gcc filename.c -o Myexe
```

For example:

```bash
gcc SinglyLinearLinkedList.c -o Myexe
```

### Run

**On Windows:**

```bash
.\Myexe
```

**On Linux/macOS:**

```bash
./Myexe
```
